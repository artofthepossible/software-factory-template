# Contributing

Thanks for contributing! Please read the [Code of Conduct](CODE_OF_CONDUCT.md) first.

## Getting started

See [docs/development.md](docs/development.md) for setup. In short: `make setup && make test`.

## Pull requests

- Keep PRs small and focused; link the issue they address.
- Use Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:` ...).
- Add or update tests and docs with your change.
- `make lint test` must pass; the PR template checklist must be complete.

## Reporting bugs and requesting features

Use the issue templates. For security issues, follow [SECURITY.md](SECURITY.md) instead.
